# Лаборо — редизайн сайта

Черновик нового сайта ООО «НИЦ «Лаборо» (экологическая документация). Это рабочая версия для согласования, не официальный сайт; действующий сайт — [ooolaboro.ru](https://ooolaboro.ru).

**Текущая версия: 1.003** • https://laboro-site.github.io/

## Что где лежит

| Путь | Что это |
| --- | --- |
| `index.html` | Последняя версия — открывается по основной ссылке |
| `versions/` | Все итерации: `laboro-v1.001.html`, `laboro-v1.002.html`… |
| `concepts/` | Три исходных концепта дизайна (выбран первый) |
| `404.html` | Страница 404 |
| `og.jpg` | Картинка-превью ссылки (1200×630) |
| `docs/` | Контекст проекта (`HANDOFF.md`), план переезда с Tilda, варианты логотипа |
| `source/` | Исходники сборки и автотесты |

## История версий

- **1.003** — превью для ссылок (Open Graph, тёмный первый экран); страница 404 в светлой теме по умолчанию.
- **1.002** — меню «Услуги»: правые колонки уже, левые шире, убран лишний отступ.
- **1.001** — правки владельцев: светлая тема по умолчанию, убраны 12 сокращений, новый каталог с поиском, убраны номера блоков, обновлены команда и благодарности.

## Сборка

```
cd source/fonts && npm install && cd ..
mkdir -p dist
python3 src/build.py      # → dist/index.html и dist/laboro-v<VERSION>.html
node src/qa.js            # автотесты, нужен Playwright
```

Страницы закрыты от индексации поисковиками (`robots.txt` и метатег `noindex`).
